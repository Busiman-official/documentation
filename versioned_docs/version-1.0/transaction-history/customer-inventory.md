# Customer Inventory

Access and manage customer-specific inventory data through the dedicated customer inventory modal, providing detailed insights into customer holdings and transaction history.

## 🎯 **Accessing Customer Inventory**

### From Transaction History

- **Customer Filter**: Apply customer filter in transaction history
- **Customer Inventory Button**: Appears in top action bar when customer filter active
- **Modal Interface**: Opens dedicated customer inventory view
- **Context Preservation**: Maintains current warehouse and filter context

## 👥 **Customer Inventory Modal**

### Modal Features

- **Multi-customer Support**: View inventory for all selected customers
- **Customer Grouping**: Groups inventory by customer when multiple selected
- **Search Functionality**: Search across all customer inventory
- **Real-time Updates**: Reflects current inventory status

### Inventory Display

#### Product Table

Shows products currently held by customers:

| Column                | Description                             |
| --------------------- | --------------------------------------- |
| **Customer**          | Customer name (when multiple customers) |
| **Product**           | Product name and model                  |
| **Serial Number**     | Individual item serial numbers          |
| **Quantity**          | Quantity held (for bulk items)          |
| **Additional Fields** | Custom serial number information        |

#### Data Types

- **Serialized Items**: Shows individual serial numbers
- **Bulk Items**: Shows total quantities for non-serialized products
- **Mixed Inventory**: Handles both serialized and bulk items

## 🔍 **Search & Filter**

### Within Customer Inventory

- **Search Box**: Located at top of modal
- **Real-time Filtering**: Results update as you type
- **Multi-field Search**: Searches products, serial numbers, customers
- **Case-insensitive**: Search works regardless of case

### Search Scope

- **Product Names**: Official and alias product names
- **Serial Numbers**: Individual item serial numbers
- **Customer Names**: Customer organization names
- **Additional Fields**: Custom serial number information

## 📊 **Data Organization**

### Table Features

- **Sorting**: Click column headers to sort data
- **Pagination**: Navigate through large datasets
- **Responsive Design**: Optimized for desktop and mobile
- **Export Ready**: Data structured for export functionality

### Customer Grouping

- **Single Customer**: Simplified view without customer column
- **Multiple Customers**: Shows customer column for organization
- **Grouped Display**: Related products grouped by customer

## 🔗 **Integration Points**

### Transaction History Links

- **Transaction Access**: Links back to related transactions
- **Context Preservation**: Maintains filter and search state
- **Detailed Views**: Access complete transaction information

### Customer Management

- **Customer Profiles**: Links to customer detail pages
- **Account Management**: Access customer account information
- **Contact Information**: Customer contact details and history

## 💡 **Best Practices**

### Customer Inventory Management

- **Regular Review**: Monitor customer inventory levels
- **Serial Tracking**: Use serial numbers for valuable items
- **Transaction Links**: Review related transaction history
- **Customer Communication**: Use data for customer inquiries

### Search Efficiency

- **Specific Terms**: Use product names or serial numbers
- **Customer Focus**: Search within specific customer inventory
- **Context Awareness**: Consider warehouse and store context
